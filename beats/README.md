# 📁 ПАПКА ДЛЯ ВАШИХ БИТОВ

Просто закидывайте сюда свои `.mp3` или `.wav` файлы!
Сайт автоматически подтянет их, распарсит название, тональность и темп, и сразу выведет в плеер и каталог.

### 🏷 Формат названия файлов:
```
Название_Тональность_BPM.mp3
```
(или `.wav`)

### 📌 Примеры:
- `BLOCK EYES_Am_160BPM.mp3` -> Название: **BLOCK EYES**, Тональность: **Am**, Темп: **160 BPM**
- `Phantom_C#m_190BPM.wav`   -> Название: **PHANTOM**, Тональность: **C#m**, Темп: **190 BPM**
- `GRAVEYARD SHIFT_Fm_140.mp3` -> Название: **GRAVEYARD SHIFT**, Тональность: **Fm**, Темп: **140 BPM**
- `NO MERCY_D#m_145BPM.mp3`  -> Название: **NO MERCY**, Тональность: **D#m**, Темп: **145 BPM**
