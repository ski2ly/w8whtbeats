# Папка для MP3-превью треков

Сюда можно загружать 10-15 секундные MP3 файлы с превью ваших битов.

### Имена файлов по умолчанию:
- `ww-01.mp3` — для бита "GRAVEYARD SHIFT"
- `ww-02.mp3` — для бита "PHANTOM BLOCK"
- `ww-03.mp3` — для бита "WAIT WHAT?"
- `ww-04.mp3` — для бита "COLD BLOOD"
- `ww-05.mp3` — для бита "STATIC REAPER"
- `ww-06.mp3` — для бита "MIDNIGHT AMBIENCE"

> **Примечание:** Если MP3 файл еще не добавлен, сайт автоматически генерирует процедурный аналоговый 808 дарк-трэп луп на Web Audio API в соответствии с тональностью и BPM трека. Как только вы положите сюда реальный MP3 файл, плеер будет воспроизводить именно его!
